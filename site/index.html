Shiftbase

Workforce management for small and medium shift-based businesses.

View on GitHub

What it does

  • Organizations, locations, departments, positions, qualifications; owner / admin / manager / employee roles
  • Weekly schedule with drafts, publishing, open shifts, templates and recurring shifts
  • Validation: overlaps, leave, qualifications, availability, rest time, weekly hours
  • Availability, time off, shift swaps and open-shift applications with approvals
  • Clock in/out, breaks, manager corrections, timesheet approval, CSV export
  • Notifications, reports, append-only audit log

Try it locally

git clone https://github.com/gbogdev/Shiftbase.git
cd Shiftbase
python -m venv .venv && . .venv/bin/activate
pip install -r backend/requirements-dev.txt
cd frontend && npm install && npm run build && cd ../backend
export SECRET_KEY=dev DEBUG=true SECURE_SSL_REDIRECT=false
python manage.py migrate
python manage.py seed_demo
python manage.py runserver

Open http://localhost:8000. The seed command creates a fictional demo business and prints the logins. Docker Compose is also supported; see the README.

About this page

This is a static project page. Shiftbase needs a Django server and a database, which GitHub Pages cannot run, so there is no live demo here. It has not had an independent security review; see docs/SECURITY.md in the repository for what is and is not covered.
